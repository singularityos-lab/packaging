# Singularity packaging

Packaging recipes for [Singularity Desktop](https://github.com/singularityos-lab/singularity-desktop),
maintained by Singularity OS for Linux distributions.

Recipes are grouped by package format. See [rpm/](rpm/) for the current RPM
recipes, source packages and build instructions, including the Nobara 44 snapshot.

These recipes and package snapshots are intended for distribution packagers,
not end users. Distribution-specific configuration, dependency adjustments or
desktop integration may still be missing. Packagers must review and complete
the packaging before distributing it to users.
